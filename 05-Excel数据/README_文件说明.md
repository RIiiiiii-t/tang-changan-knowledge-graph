# 05-Excel数据使用说明

本目录于 2026-08-21 完成整理。日常工作优先使用前四个编号文件夹；旧版本统一保存在 `99-历史归档`，避免误用。

## 文件夹用途

- `01-当前总表`：当前汇总数据。优先交付、转换 JSON 和平台迁移时使用。
- `02-正式模板与协作表`：空白录入模板及三人协作编号登记表。
- `03-已完成批次`：《唐两京城坊考》卷一至卷四的分卷工作簿，供溯源和复核使用。
- `04-样例与平台导入`：小型样例 v10 与目前最新的平台导入包 v6。
- `99-历史归档/20260821_整理前`：整理前的旧版本、中间版本及 v1—v6 历次平台包备份。

## 使用原则

1. 查阅当前完整数据，打开 `01-当前总表`。
2. 新建录入批次，复制 `02-正式模板与协作表` 中的正式模板，不直接修改空白母版。
3. 新建实体编号前，先查协作登记表和当前总表。
4. `99-历史归档` 只用于回溯，平时不要从中继续录入。
5. Godot 或网页平台不直接读取 Excel 时，应从当前总表转换生成 JSON；Excel仍作为人工审核源文件。
