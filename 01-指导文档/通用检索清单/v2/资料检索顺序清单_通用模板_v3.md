# 资料检索顺序清单（通用模板 v3）

> 每一份资料在正式提取前，都必须先完成本清单的全部步骤。
> 清单完成后存档，作为该资料的检索记录和后续批次的定位依据。
>
> **核心原则：逐段通读、全量登记、不遗漏任何可录入对象。**
>

## 第二部分：格式判定与处理路径

> 根据资料格式选择对应处理路径。epub/文字版 PDF 优先使用，扫描版 PDF 作为备选参考。

### 路径 A：epub / 文字版 PDF（优先）

1. 提取全文纯文本（去除 HTML/XML 标签、样式代码）。
2. 确认文字语言（繁/简），记录到基本信息表。
3. 识别全书结构（目录、章节标题、分卷标记）。
4. 全文可搜索，直接用关键词定位条目。

### 路径 B：PDF 扫描版（备选）

1. 读封面和版权页，确认基本信息。
2. 精读目录页，确定分卷结构和页码范围。
3. 抽样检查 3–5 页，确认清晰度和排版特征。
4. 逐页导出图片 → 视觉阅读 → 提取文字。

### 路径 C：混合使用

如果同一著作同时有 epub 和扫描版 PDF：
- 以 epub 为主工作版本（快速检索和全量提取）。
- 扫描版 PDF 作为辅助参考（核对地图、图表、排版细节）。

## 第五部分：逐段通读与全量提取

> 在确定的范围内逐段阅读，不跳过任何段落。

### 提取顺序（每段执行）

1. **原文摘录**：逐字抄录（不做改写），标注卷次和位置。夹注用〔〕标注。
2. **实体识别**：提取**所有**可录入对象（坊、市、街道、城门、建筑、人物、事件、以及目录未列出的宅第/寺塔/水渠/碑刻/官署等）。
3. **关系识别**：方位关系、归属关系、连接关系、人物关系、时间关系。
4. **二级来源记录**：如原文引用了其他古籍，记录为子来源。
5. **置信度评估**：
   - 原文直接陈述 → ≥ 0.90
   - 需推理得出 → 0.75–0.85
   - 存疑/争议 → ≤ 0.70，备注说明

### 提取格式

```
【位置】卷 X / 第 X 段
【原文】（逐字抄录，夹注用〔〕标注）
【实体】
  - 名称：XX，类型：XX，描述：（简要）
【关系】
  - XX —关系— XX（原文："…"）
【二级来源】
  - 引《XX》卷X："…"
【存疑】（如有）
```
