# 资料检索顺序清单（通用模板 v2）

> 每一份资料在正式提取前，都必须先完成本清单的全部步骤。
> 清单完成后存档，作为该资料的检索记录和后续批次的定位依据。
>
> **核心原则：逐页通读、全量登记、不遗漏任何可录入对象。**

## 第二部分：结构探查与边界确定

> 本阶段的唯一目标是确定"从第几页读到第几页"，以及全书的组织逻辑。

### 步骤 1：读封面和版权页

确认书名、作者、出版年份、出版社、ISBN。记录到上表。

### 步骤 2：精读目录

定位全书结构，回答以下问题：

- 全书分为几卷/几章？各卷/章的主题是什么？
- 哪些章节记载长安城（而非洛阳或其他城市）？
- 长安城内容的起止页码是什么？
- 是否有地图、平面图、索引？（记录页码，后续单独提取）
- 是否有附录、补遗、考证？（可能包含未列入目录的条目）
- 目录中列出的最小粒度单位是什么？（坊？建筑？人物？）

## 第四部分：逐页通读与全量提取

> 在第二部分确定的扫描边界内，**每一页都完整阅读，不跳过任何段落。**

### 提取顺序（每页执行）

1. **原文摘录**：逐字抄录本页所有与长安城相关的记载（不做改写），标注页码和卷次。夹注用〔〕标注。
2. **实体识别**：从原文中提取**所有**可录入对象，包括但不限于：
   - 坊（Fang）、市（Market）、街道（Street）、城门（Gate）、建筑（Building）
   - 人物（Person）、事件（Event）
   - 以及目录未列出但文内出现的：宅第、寺塔、水渠、碑刻、墓葬、官署等
3. **关系识别**：提取方位关系（东/西/南/北）、归属关系（属于/位于）、连接关系（接/通/连）、人物关系（建/修/居/访/葬）、时间关系（始建/扩建/毁于/改名）。
4. **二级来源记录**：如原文引用了其他古籍，记录为子来源（书名、卷次、被引内容概要）。
5. **置信度评估**：
   - 原文直接陈述 → confidence ≥ 0.90
   - 需推理得出 → confidence 0.75–0.85
   - 存疑/争议 → confidence ≤ 0.70，备注中说明

### 提取格式（每页统一使用）

```
【页码】第 X 页（卷 X）
【原文】（逐字抄录，夹注用〔〕标注）
【实体】
  - 名称：XX，类型：XX，描述：（简要说明）
  - 名称：XX，类型：XX，描述：（简要说明）
  ...（本页所有实体，不限预设类型）
【关系】
  - XX —关系— XX（原文："…"）
  ...
【二级来源】（如引用其他古籍）
  - 引《XX》卷X："…"
【存疑】（如有）
```

## 第八部分：检索完毕检查

完成本资料全文通读后，逐项确认：

- [ ] 扫描边界内的每一页是否都已阅读？

- [ ] 二级来源（引文出处）是否已记录？
