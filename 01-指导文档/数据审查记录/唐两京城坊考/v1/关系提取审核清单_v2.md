# 关系提取审核清单（v2）

> 基于宫城摘录审核经验总结，适用于卷一全文逐批提取
> 更新日期：2026-08-06

---

## 一、提取阶段检查项

### 1.1 覆盖完整性

- [ ] 主体文本中的空间归属关系（LOCATED_IN）全部提取
- [ ] 方位关系全部提取（EAST_OF, WEST_OF, SOUTH_OF, NORTH_OF, NORTHEAST_OF）
- [ ] 门序关系全部提取（如"承天门东长乐门"→ 长乐门 EAST_OF 承天门）
- [ ] 正对关系（FACING）提取（如"南直承天门"）
- [ ] 邻接/靠近关系（ADJACENT_TO, NEAR）提取
- [ ] **注解（〈〉）中的人物关联（ASSOCIATED_WITH）全部提取**
- [ ] **注解中的历史事件（INVOLVED）全部提取**
- [ ] **名称变更记录到实体表 name_rename_history 字段**
- [ ] 跨段落关系不遗漏（如 A 段落提到 B，B 段落反过来描述 A）

### 1.2 entity_key 匹配

- [ ] 关系两端的 entity_key 在实体表中存在
- [ ] 未匹配的实体名称标记为"[待收录]"，汇总报告
- [ ] 同一实体的不同写法（如"太极宫"vs"宫城"）正确映射

### 1.3 去重

- [ ] 同一对实体的重复关系合并（source_key + target_key + relation_type 三元组唯一）
- [ ] 双向关系正确处理（如 A EAST_OF B 和 B WEST_OF A 不重复录入，只取一种）

---

## 二、字段规范检查项

### 2.1 relation_label（简体白话文）

- [ ] 使用简体字
- [ ] 白话文描述，不直接摘抄原文
- [ ] 包含从原文中可获取的所有信息（不只是概括关系类型）
- [ ] 示例：✓ "长乐门在承天门东侧，两者同属宫城南面城门" ✗ "位于…东侧"

### 2.2 note（简体白话文）

- [ ] 使用简体字
- [ ] 补充 relation_label 未涵盖的背景信息
- [ ] 标注数据来源（如"《朝野佥载》记载"）

### 2.3 evidence_quote（繁体原文）

- [ ] 保留繁体
- [ ] 尽可能完整引用，不截断
- [ ] 包含足够上下文以支持关系的成立

### 2.4 confidence

- [ ] 原文明确陈述：0.9
- [ ] 推理/间接证据：0.75-0.85
- [ ] 存疑/仅注解提及/宫内隔门：0.6

---

## 三、史料片段检查项

### 3.1 content（繁体原文）

- [ ] 直接写原文，不加书名前缀（如不加"《朝野佥载》："）
- [ ] 保留繁体
- [ ] 引用完整，不截断

### 3.2 note（简体白话文）

- [ ] 使用简体字
- [ ] 包含出处书名（如"《旧书王琚传》"）
- [ ] 概括事件内容

### 3.3 关联实体

- [ ] 每条典故关联到正确的实体（如高颎故事关联承天门，不是宫城）

---

## 四、实体表检查项（每批新增实体）

### 4.1 字体规范

- [ ] name：简体
- [ ] aliases：简体
- [ ] description_modern：简体白话文
- [ ] description_quote：繁体原文

### 4.2 名称变更

- [ ] 如有改名历史，记入 name_rename_history 字段
- [ ] 包含年份（如可考）和说明

### 4.3 合并/去重

- [ ] 不因别名创建独立实体（如通训门不独立于凤皇门）
- [ ] 同一物理实体只有一个 entity_key
- [ ] 同名但不同位置的实体正确区分（如玄武门(内) vs 定武门的别名玄武门）

---

## 五、常见问题与处理方案

| 问题 | 处理方案 |
|------|---------|
| 注解中的人物不在实体表 | 补录为 Person 实体 |
| 注解中的地点不在实体表 | 评估是否值得录入，或仅在关系中标注"[待收录]" |
| 同一对实体有多条不同来源的关系 | 保留最具信息量的一条，其余记入 note |
| 方位关系不明确（如"东"可能是东邻或东面某处） | 根据上下文判断，不确定时降低 confidence |
| 门序关系（如"次东"）| 需要推断中间门的位置，标注 confidence=0.8 |
| 宫内隔门（如恭礼门、安仁门）的 LOCATED_IN | 可添加但 confidence=0.6 |
| CENTER 类型 | 不使用，合并入 LOCATED_IN 并在 note 中标注"正南/正中" |
| NAME_FORMERLY 类型 | 不作为关系，改为实体 name_rename_history 字段 |

---

## 六、每批次交付格式

1. **审核表（Markdown）**：按关系类型分组，每条含编号、source→target、relation_label、evidence_quote、note
2. **待决问题清单**：标记未匹配的实体、不确定的关系
3. **用户确认后**：写入 Excel，更新累积数据

## 七、宫城摘录验证案例（参考标准）

以下 34 条关系为已验证的参考标准，后续提取应达到同等覆盖度：

- LOCATED_IN: 18 条（宫城南面五门、东西藏库、东西面门、北面门、景风门→皇城、宫城→西京、恭礼门/安仁门/武德殿）
- EAST_OF: 3 条（长乐门、永春门、安礼门）
- WEST_OF: 2 条（广运门、永安门）
- SOUTH_OF: 1 条（通明门南于嘉猷门）
- NORTHEAST_OF: 1 条（大明宫东北于宫城）
- NEAR: 2 条（东左藏库邻恭礼门、西左藏库临安仁门）
- FACING: 1 条（定武门南直承天门）
- ASSOCIATED_WITH: 6 条（高颎→承天门、隋文帝→定武门、权梁山→长乐门、王琚→承天门、代宗→承天门、尉迟敬德→定武门）

史料片段 8 条：承天门 4 条、长乐门 1 条、定武门 2 条、大明宫 1 条。
