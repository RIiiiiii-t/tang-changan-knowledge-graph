## 三、最终确立的工作标准

### 关系提取方法

**方案 A：AI 直接阅读原文**（与宫城摘录相同方式）
- AI 逐段阅读约 1000-2000 字的文本段
- 理解语义后手写所有关系
- 不使用 LLM API 辅助，不使用纯正则匹配
- 关系表从头重写，不复用旧的 570 条自动提取结果

### 关系提取覆盖范围

每段文本必须提取：
1. **主体文本中的关系**：空间归属、方位、邻接
2. **注解（〈〉）中的关系**：人物关联、历史事件、名称变更
3. **史料典故**：每条独立记录到史料片段表

### 关系类型体系（13 类）

| 代码 | 中文 | 适用情况 |
|------|------|----------|
| LOCATED_IN | 位于…内 | 建筑位于区域内 |
| LOCATED_ALONG | 位于…沿线 | 位于街道沿线 |
| EAST_OF | 位于…东侧 | 明确东西方位 |
| WEST_OF | 位于…西侧 | 明确东西方位 |
| SOUTH_OF | 位于…南侧 | 明确南北方位 |
| NORTH_OF | 位于…北侧 | 明确南北方位 |
| NORTHEAST_OF | 位于…东北 | 复合方位 |
| ADJACENT_TO | 相邻 | 直接相邻 |
| NEAR | 靠近 | 空间接近 |
| FACING | 正对 | 南北/东西正对（如定武门南直承天门） |
| CONNECTS_TO | 连接 | 街道与城门连接 |
| ASSOCIATED_WITH | 相关 | 人物与地点关联 |
| INVOLVED | 涉及 | 事件涉及实体 |

### Excel 表结构

| 工作表 | 列数 | 新增列 |
|--------|------|--------|
| 实体表 | 13 | description_quote (col13) |
| 关系表 | 11 | evidence_quote (col11) |

### 置信度标准

| 情况 | 置信度 |
|------|--------|
| 原文明确陈述 | 0.9 |
| 推理/间接证据 | 0.75-0.85 |
| 存疑/仅注解提及 | ≤ 0.6 |
