## 二、v4→v5 变更详情（P1/P2/P3 修正）

### P1：description 改写 + 新增 description_quote 列

**问题**：description 字段直接照录古文原文（繁体），可读性差，不利于前端展示。

**修正**：
- description 列改为简洁的**现代中文描述**（通过 qwen-plus 批量翻译 539 条）
- 新增第 13 列 **description_quote**，保留原文引用（繁体中文）用于溯源
- source_key（TC-REF-001）关联来源表，史料片段表保存代表性原文

**示例**：

| 实体 | description（现代中文） | description_quote（原文） |
|------|----------------------|------------------------|
| 西京 | 西京即唐长安城，初称京城，为隋开皇二年所建新都。 | 唐西京初曰京城，隋之新都也，開皇二年所築。 |
| 承天门 | 承天门为宫城正南门，隋开皇二年建，历经多次更名，门上有楼，门外设朝堂、肺石与登闻鼓。 | 正南承天門，〈隋開皇二年作…〉 |
| 宫城 | 宫城东西四里、南北二里二百七十步，周长十三里一百八十步，高三丈五尺。 | 宮城，東西四里，南北二里二百七十步… |
| 禁苑 | 禁苑即隋代大兴苑，为唐代长安城北皇家园林。 | 禁苑者，隋之大興苑也 |

### P2：Layer 2 方位关系补充

**问题**：v4 关系表中方位关系（NORTH_OF/EAST_OF/WEST_OF/SOUTH_OF）几乎为零。

**修正**：重写 Layer 2 提取逻辑，新增 5 种古文方位模式：
- Pattern A：`X之東/西/南/北` → 11 条
- Pattern B：`X門東Y門` / `次東Y` → 6 条
- Pattern C：`東為X` / `X北為Y` / `X南有Y` → 15 条
- Pattern D：`entity_name + 方向字`（广泛扫描）→ 37 条
- Pattern E：同网格位置 NEAR → 87 条

**结果**：方位关系从 ~0 提升到 **69 条**（NORTH_OF 23 + EAST_OF 23 + WEST_OF 18 + SOUTH_OF 5）。

### P3：relation_label 和 note 格式修正

**问题**：v4 的 relation_label 使用通用标签（"位于…内"），note 直接粘贴原文 evidence。

**修正**：根据实体类型和关系类型生成描述性文字。

**示例**：

| 关系 | label | note |
|------|-------|------|
| 丹鳳門 → LOCATED_IN → 大明宮 | 位于大明宫内 | 丹凤门是大明宫的城门之一 |
| 長樂門 → EAST_OF → 承天門 | 位于承天门东侧 | 长乐门在承天门的东面 |
| 隋文帝 → ASSOCIATED_WITH → 龍首原 | 与龙首原相关 | 隋文帝与龙首原存在历史关联 |
| 太極殿 → LOCATED_IN → 宮城 | 位于宫城内 | 太极殿是宫城内的殿宇建筑 |

## 六、已确立的工作原则（更新版）

1. **description 用现代中文**：简洁可读，不超过60字，保留关键信息
2. **description_quote 保留原文**：繁体中文逐句照录，用于溯源
3. **全量提取**：凡文献中出现的命名实体全部录入，不做取舍
4. **分类必须准确**：城门/Gate 与内门/Building 严格区分；宫殿区与殿宇严格区分
5. **每步修改必须经用户确认**：先报告问题和方案，用户确认后再执行
6. **relation_label 和 note 用描述性文字**：不使用通用标签或直接贴原文
7. **方位关系需覆盖古文模式**：X之東/西/南/北、東為X、X門東Y門、次東Y 等
8. **仅改类别不删条目**：除非明确为非唐代实体（如汉代旧宫），否则不删除
9. **不好归类的放其他**：宁可保守分类，不强行归入不合适的类别
