# 唐长安城知识图谱小型样例文献选择方案 v1

> 日期：2026-08-07  
> 状态：初选完成，待团队确认与补充文献入库  
> 目的：用少量、相互补充的资料完成第一轮试填，检验六张核心主题表、坊间空间关系表及转换规则。

## 一、选择原则

1. 先用现有文献，不因试填阶段无限扩充资料。
2. 文献记载负责名称、沿革、功能和相对方位；考古资料负责位置、尺寸、道路及遗迹证据。
3. 同一重要结论尽量由两种不同性质的材料交叉支持。
4. 现代研究中的推断不能冒充史料直述；复原坐标必须注明地图或测量来源。
5. 试填期间不追求覆盖108坊，优先选择能够同时检验多张表的对象群。

### 现有文献能够直接支持的样例内容

- 城门：承天门、朱雀门、明德门、春明门、通化门等名称、隶属和相对位置。
- 道路：承天门街、横街、朱雀门街等走向、连接对象及部分宽度原值。
- 水渠：龙首渠、永安渠、清明渠的水源、走向、经过区域与供水对象。
- 坊：平康坊、崇仁坊、兴庆坊、胜业坊、永嘉坊的内部设施与功能线索。
- 尺度：宫城、皇城、横街、承天门街等以里、步、丈记载的原始尺度。
- 功能规则：皇城官署集中、东市周边商业与旅宿活动、宫苑与水渠联系等候选规则。

## 四、建议的小型样例对象群

选择东部坊区、宫苑、水渠与中轴道路组合，可以让一批材料同时测试六张核心表。

| 类别 | 建议对象 | 选择理由 |
|---|---|---|
| 5个坊 | 平康坊、崇仁坊、兴庆坊、胜业坊、永嘉坊 | 功能类型较丰富，靠近东市或兴庆宫，适合测试坊功能和坊间空间关系 |
| 3条道路 | 朱雀门街（天街）、承天门街、横街 | 有明确连接、走向和尺度记载，可测试道路分级与尺度比较 |
| 2条水渠 | 龙首渠、永安渠 | 分属城市东部和西部供水系统，便于比较水源、走向和供水范围 |
| 5座城门 | 明德门、朱雀门、承天门、春明门、通化门 | 可组成外郭城—皇城—宫城及东西交通关系链 |
| 3组尺度 | 横街与承天门街宽度；皇城与宫城东西尺度；道路文献宽度与考古测量宽度 | 同时检验古代单位保留、标准化换算、可比性和误差说明 |
| 3条候选规则 | 皇城官署集中；东市周边商业和旅宿活动较集中；宫苑布局与水渠供水存在联系 | 有正面例证，也容易寻找例外和反证，适合测试规则审核流程 |

## 五、暂不建议作为第一批主证据的材料

- 普通百科、旅游介绍和自媒体复原图：可用于发现线索，不能直接作为坐标、尺度或历史结论的正式证据。
- 未注明底图、坐标系和测绘依据的网络地图：不得录入经纬度。
- 只有现代结论、没有引文或考古出处的文章：只能标记为待核线索。
- 洛阳城材料：可作制度比较，不直接代替唐长安城数据。

## 六、第一轮实际工作顺序

1. 先用 TC-REF-0001～0003 完成上述对象的文献片段定位。
2. 对城门位置、道路宽度、水渠线路和坐标类字段列出“缺少考古依据”标记。
3. 优先取得 TC-REF-0004；如暂时无法取得，尺度与坐标保持空白，不做猜测。
4. 使用 TC-REF-0005～0008补充水系、道路排水和功能规则，但重要数值尽量回溯到原始考古报告。
5. 完成少量试填后，再决定是否扩大文献范围。
