## 四、发布安全验收

公众图谱接口只返回同时满足 `published + public` 的实体和关系。目前本批数据尚未正式发布，因此：

- 公众图谱节点：0；
- 公众图谱关系：0；
- 公众搜索结果：0。

这说明前端换壳没有绕过审核流程，也没有把待审核知识提前公开。

当 API 暂时不可用时，前端安全降级为 0 和空图，不再展示青瓷演示数字或青瓷样例图谱，避免让旧数据被误认为当前数据。
