# 多人全量提取协作规范

## 一、责任结构

采用“按文献生产、按专题复核、集中合并”。

- 项目负责人：分配文献与编号段，维护主实体登记表，批准审核状态，执行最终合并和平台导入。
- 主提取者：完整处理所分配文献，不把该文献中的不同专题转交他人拆分摘录。
- 专题复核人：跨文献检查本专题的字段与语义一致性，不重新摘录，不擅自改号。
- 合并人员：执行查重、编号冲突处理、专题表与实体/关系同步、结构校验；原则上由项目负责人承担。

允许一人兼任多个角色，但同一批次的主提取与最终审核不得由同一人独立完成。

## 二、开始前的三张登记表

### 1. 任务分配表

每篇文献一行，至少记录：

`batch_id`、`source_key`、`文献题名`、`主提取者`、`涉及专题`、`专题复核人`、`计划日期`、`当前状态`、`交付文件名`、`备注`。

状态使用：`未开始`、`提取中`、`待专题复核`、`待集中审核`、`退回修改`、`审核通过`、`已合并`。

### 2. 编号段登记表

分别为 `TC-REF`、`TC-CHUNK`、各实体前缀、`TC-REL` 预留不重叠区间，记录：

`编号类型`、`起始编号`、`结束编号`、`分配对象`、`batch_id`、`已用至`、`分配人`、`日期`、`备注`。

规则：

- 已使用编号永久保留，删除记录后也不重复利用。
- 不得使用他人编号段；预计不足时向负责人申请新段。
- 已存在公共实体必须复用稳定编号，不因分配了新编号段而重复建实体。
- 来源编号由负责人先分配，一篇文献通常只建一个来源记录；不同版本确需分开时说明版本差异。

### 3. 主实体登记表

集中记录已确认实体，至少包含：

`entity_key`、`标准名称`、`实体类型`、`别名`、`时期`、`识别说明`、`首次来源`、`当前状态`。

提取者在新建实体前按标准名、别名和位置查重。疑似同一对象时在个人批次中填“待查重对象：候选编号”，不得自行合并或创建同名实体。

## 三、单篇文献生产流程

1. 领取任务、复制正式模板并登记 `batch_id`。
2. 读取稳定样例、填写说明、代码对照、转换规则和主实体登记表。
3. 登记来源，保留版本和页码定位信息。
4. 按原文顺序摘录“最小但完整”的连续片段。
5. 复用或新建实体，再建立关系；所有关系端点必须存在。
6. 填写该文献涉及的全部专题表，不因主任务专题不同而漏掉同段文字中的其他空间对象。
7. 分离基础事实、研究解释与科普表达；推论保留作者、限制和反例。
8. 将专题表同步到实体表与关系表，完成个人批次自检。
9. 输出审核摘要后停止，提交专题复核；不得自行标记审核通过或发布。

## 四、专题复核

专题复核按跨文献视角进行，检查：

- 标准名称、别名和实体类型是否一致；
- 道路序位、坊坐标、空间方向、关系方向是否符合统一规则；
- 数值是否保留原单位、换算依据和精度；
- 同类专业字段是否使用统一词表；
- 专题记录是否已经同步形成实体或关系；
- 研究解释是否误写成基础事实；
- 是否存在应补充的反例或适用范围。

复核人只写问题和建议。涉及原文摘录、编号、实体合并或语义改变的修改，退回主提取者或交由合并人员处理，并保留修改记录。

## 五、批次交付清单

每个批次必须交付：

- 一份独立 Excel 工作簿；
- 一份审核摘要，列明来源、片段、实体、关系和各专题表新增/修改数量；
- 关键引文及页码/图号；
- 新建实体清单、复用实体清单和待查重清单；
- 推断项、争议项、反例和待确认项；
- 自检结果及尚未解决的警告。

建议文件名：`BATCH-序号_提取者_文献简称_YYYYMMDD.xlsx`。禁止多人轮流编辑同一个个人批次文件。

## 六、集中合并

按以下顺序执行：

1. 冻结待合并的个人批次，建立只读副本或 Git 提交。
2. 合并来源并核对版本；不得仅按题名粗暴去重。
3. 使用主实体登记表处理同物异名、同名异物和“待查重”对象。
4. 处理编号冲突并记录旧编号到新编号的映射，不直接静默改号。
5. 合并片段，保持原文、定位和来源不变；相同连续原文可复用片段，不重复制造证据。
6. 合并专题表，并重新生成或同步实体表与关系表。
7. 检查研究推论与所解释对象、证据片段和来源的连接。
8. 对整个合并工作簿运行转换和结构校验，要求 0 错误；所有警告必须修复或逐条解释。
9. 输出集中审核清单，等待人工批准；未经批准不进入发布白名单。

## 七、禁止事项

- 禁止把同一文献按专题拆给多人分别摘录。
- 禁止直接在正式空白模板资产或稳定样例资产上追加个人数据。
- 禁止个人批次直接写入平台、修改为“审核通过”或“已发布”。
- 禁止专题复核人为了方便而重新编号或无记录地合并实体。
- 禁止仅复制专题表而漏掉实体表、关系表、来源和片段证据。
- 禁止用文件名、题名或模型记忆代替页码、图号和原文核对。
