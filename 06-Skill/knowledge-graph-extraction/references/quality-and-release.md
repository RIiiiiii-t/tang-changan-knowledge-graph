# 质量与发布验收

## 单批质量检查

- 来源编号存在且元数据足够定位。
- 片段原文连续、未润色，页码/图号/行号可核查。
- 实体编号唯一，名称和别名查重。
- 关系端点存在，方向与标签一致。
- 专题表和通用实体/关系表同步。
- 基础事实与研究解释分层。
- 坐标、尺度和单位保留原单位、换算方式和精度。
- 审核状态与备注一致。

## 结构阻断项

出现以下任一情况，不得生成可发布包：

- 悬空实体、关系端点、来源或证据片段。
- 重复稳定编号。
- 关系引用未发布且未同批发布的端点。
- 片段引用未发布且未同批发布的来源。
- 待审核记录进入审核白名单。
- 自动转换静默丢弃不完整记录。

## 平台验收顺序

1. 记录导入前数量。
2. 导入审核白名单并记录导入后数量。
3. 再次导入，确认幂等。
4. 选择性发布并确认发布依赖。
5. 重建公开图谱和检索索引。
6. 对比 PostgreSQL 与 Neo4j 的公开实体、关系状态。
7. 网页查看首页总量和已发布数量。
8. 搜索一个实体、一个片段和一个别名。
9. 查看至少两个一跳图谱，逐条核对预期关系。
10. 形成发布与网页验收报告，并更新看板。
