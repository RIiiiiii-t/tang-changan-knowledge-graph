# 唐长安城知识图谱数据提取 v3.1

以“小批量提取—写入小型样例—人工审核—转换校验—审核后发布”为唯一主流程。正式录入模板只保存表结构；试录和迭代数据写入小型样例工作簿。

## 开始前

1. 读取项目看板，确认当前工作版本、审核状态和下一项任务。
2. 读取小型样例工作簿中的“填写说明、代码对照、转换规则表”。
3. 查重来源、实体、关系和编号；不得凭记忆续号。
4. 判断资料类型：古代文献/考古/测量/复原图属于基础事实证据；现代论文的分析与推论属于研究解释。
5. 需要字段细节时读取 [data-model.md](references/data-model.md)；需要验收规则时读取 [quality-and-release.md](references/quality-and-release.md)。
6. 两人及以上协作或进入全量提取时，必须读取 [collaboration.md](references/collaboration.md)，先建立任务分配和编号登记，再开始提取；当前采用成员A（负责人）、成员B、成员C的三人协作方案。

## 工作文件

- 新批次复制 [正式录入模板](assets/唐长安城知识图谱录入模板_阶段二_v1.xlsx)，不得直接覆盖资产原件。
- 不确定填写方式时对照 [稳定样例 v10](assets/小型样例_第1批_文献片段与基础对象_v10.xlsx)；样例用于示范和回归，不作为新批次继续追加的工作簿。
- 多人协作时复制 [协作登记模板](assets/多人全量提取协作登记模板_三人编号段版.xlsx)，由成员A（项目负责人）维护任务、编号段、主实体和交付检查记录。
- 首次交接或新成员加入时，可先阅读 [多人全量提取操作手册](assets/唐长安城知识图谱_多人全量提取操作手册_v1.docx)，再使用 Skill 执行具体批次。
- 每位提取者使用独立工作簿，文件名遵循 `批次号_提取者_文献简称_日期.xlsx`。

## 多人全量提取

采用“按文献分配、按专题复核、集中合并”，不得把同一篇文献按专题拆给多人分别摘录。

1. 一篇文献只指定一位主提取者，负责该文献中的来源、片段、实体、关系、所有相关专题表和研究推论。
2. 主提取者先复用主实体登记表中的稳定编号；无法确认是否为同一对象时标记“待查重”，不得自行新建近似实体。
3. 项目负责人按人员或批次预分来源、片段、实体、关系编号段；提取者不得越界用号，也不得回收已使用编号。
4. 主提取完成后，由道路、坊市、水文、城门/建筑、研究解释等专题复核人横向检查术语、字段、方向、坐标和关系类型；专题复核人不重复摘录原文。
5. 每篇文献或每 20—30 条记录形成一个审核批次；全部状态保持“待审核”，由项目负责人集中查重、合并和批准。
6. 只有集中合并工作簿可以运行最终转换、生成审核白名单和导入平台；个人批次不得直接发布。

开始多人任务前，输出任务分配表、编号段登记表和主实体登记表；批次交付与合并规则见 [collaboration.md](references/collaboration.md)。

### 已登记公共对象与状态

协作登记表当前包含 176 个公共对象：108 坊、25 道路、5 水渠、20 城门、8 条尺度比较和 10 条功能规则。它的作用是锁定编号、帮助查重和复用，不是正式实体表。

- 状态为“待补字段”表示对象编号和身份已登记，但来源、片段、字段或审核尚未完成；不得当作“审核通过”或“已发布”。
- 已登记对象必须复用原编号；新文献可以为它补充新的来源、片段、属性和关系，但不得另建同义对象。
- `TC-RULE-0001—0010` 当前只锁定编号和规则名称。其专题表存在字段错位待核对的问题；不得直接复用其中的来源、引文、置信度或结论字段。

## 提取顺序

按证据依赖从底到上处理：

1. 来源表：先登记文献身份、作者、年代、版本、质量等级和定位方式。
2. 史料片段：完整保留能够独立支持一个事实或判断的最小连续上下文。
3. 实体表：先复用已有实体；确需新增时再分配稳定编号。
4. 关系表：关系的两个端点必须已经存在，并引用具体片段编号。
5. 空间专题表：将同一类对象的专业字段集中录入，并按转换规则同步到实体/关系系统。
6. 研究推论表：把现代论文的论点、依据、限制和反例与基础实体连接。
7. 科普表达：默认即时生成，不把生成文本当历史事实；必须携带研究结论编号和基础证据编号。

不要因为内容“有趣”而优先提取。优先级依次为：能补齐实体端点的数据、能支撑关系的数据、能形成完整证据闭环的数据、研究解释、科普表达。

## 史料片段原则

- 不机械摘全文，也不只截一句结论。摘取“最小但完整”的连续片段，使读者不返回原书也能判断证据是否支持条目。
- 保留必要的主语、宾语、方位参照、限定词、转折、否定和作者判断；省略不影响该判断的远端内容。
- 不把多个互不相关的判断强塞进同一片段；同一连续段同时支持多条记录时可以复用片段编号。
- 原文逐字保存，不擅自繁简转换或润色；现代释义另写字段。
- 记录页码/图号/表格行号；来自复原图或表格时说明读取逻辑。
- 无可核对原文或图表定位的内容不得标为基础事实。

## 三层知识分离

- 基础事实：保存可直接核对的对象、属性和空间关系，`knowledge_layer=FACT`。
- 研究解释：保存现代研究者的分析、推论、争议和适用条件，`knowledge_layer=INTERPRETATION`；用 `InterpretiveClaim` 实体连接所解释的对象与证据。
- 科普表达：由前两层即时生成；输出时区分“史料记载”“考古发现”“学者认为”“据此可推测”。不得把推论改写成无条件事实。

## 空间专题转换

专题表是录入入口，实体表和关系表是平台统一出口。每次改专题表后必须重新转换或同步，不得只改专题表。

- 坊、市、道路、水渠、城门、地形、水体和重要建筑生成或更新对应实体。
- 坊间关系、城门—道路连接、隶属、相对方位、水渠流经等生成关系。
- 坊内平面规则通常生成 `LayoutRule`；研究者对其原因的解释生成 `InterpretiveClaim`，两者不得合并。
- 同一语义关系只保留一条稳定编号记录；重复转换必须幂等。
- 若专题字段指向不存在的端点、证据片段或来源，转换必须报错或阻断，不能静默跳过。

### 坊列与道路的已审核规则

- 坊的 `(x,y)` 是项目平面网格坐标，不是经纬度。
- `x=3` 的坊列位于“朱雀门街东第二街与东第三街之间”；必须同时生成坊邻近 `TC-ROAD-0003` 和 `TC-ROAD-0004` 两条边界关系。
- `x=-3` 的坊列位于“朱雀门街西第二街与西第三街之间”；必须同时生成坊邻近 `TC-ROAD-0008` 和 `TC-ROAD-0009` 两条边界关系。
- `TC-ROAD-0004`、`TC-ROAD-0009` 分别是东第三街、西第三街，不能因它们是坊列的一侧边界而改名为第二街。
- 坊间空间方向按统一坐标和参照对象核对；示例：平康坊位于崇仁坊南侧，关系方向为“平康坊 `SOUTH_OF` 崇仁坊”。
- 水渠与坊可同时存在“坊邻近水渠”和“水渠流经坊”，两者语义不同，不得去重为一条。

## 研究推论

每条推论至少记录：论点、作者、来源、原文片段、涉及实体、论证依据、适用范围、限制/反例、置信度和审核状态。

- 论文中的尺度、分区或因果解释不是古代事实。
- 多篇论文意见一致也不自动变为事实；可提高“研究共识程度”，但保留来源。
- 冲突观点分别保存并相互标记争议。
- “道路很宽”可以是可测量事实；“宽度由礼制造成”属于待证的研究解释。二者拆分存储。

## 审核与状态

每批只处理一个段落、一个图表或一组紧密相关材料，生成审核摘要后暂停等待用户确认。审核摘要至少列出：新增/修改数量、实体、关系、片段、关键引文、推断项、疑点和待确认项。

状态流转：`待审核 → 审核通过 → 已发布`。只有用户明确通过的记录才能改为审核通过；只有审核通过且证据依赖齐全的记录才能发布。内部备注也要同步清理，不得出现状态已通过但文字仍写“待复核”。

## 转换和发布

1. 对整个工作簿运行转换与结构校验，要求 0 错误；警告必须解释或修复。
2. 若实体表、关系表已完成统一转换和人工复核，将二者视为本批权威出口：完整保留 `AUTO` 关系，不再从专题表二次生成同义边；详细导入防护见 [quality-and-release.md](references/quality-and-release.md)。
3. 发布时从完整包生成严格审核白名单，只选择已通过记录；不得用完整包覆盖平台中的未审核数据。
4. 发布关系前检查两个端点已发布或在同批发布；发布片段前检查来源已发布或同批发布。
5. 重复导入应保持数量不变。
6. 同步 PostgreSQL、Neo4j 和 OpenSearch 后分别核对状态与数量。
7. 用网页验收首页统计、实体检索、原文检索、图谱一跳关系和证据回溯。
8. 更新项目看板，分别记录总库数量与公众可见数量。

## 稳定回归样例

当前回归基线为小型样例 v10：7 个来源、32 个片段、59 个实体、77 条关系，转换校验 0 错误、0 警告。重点回归：

- 崇仁坊同时邻近朱雀门街东第二街、东第三街；平康坊位于崇仁坊南侧。
- 大通坊同时邻近朱雀门街西第二街、西第三街，并与永安渠具有 `NEAR` 与反向 `FLOWS_THROUGH` 两种关系。
- 研究推论与基础事实分层。
- 未审核内容不进入发布白名单和公众端。

## 禁止事项

- 禁止一次性无审核地提取整本文献。
- 禁止猜测缺失坐标、宽度、名称或关系。
- 禁止只写专题表而不更新实体/关系出口。
- 禁止用来源编号代替片段级证据。
- 禁止把复原图解读、研究推论或生成的科普文字伪装成史料原文。
- 禁止在审核通过前发布。
