> 本文件夹是唐长安城知识图谱项目的数据录入工作空间。

## 文档版本管理规则

- 每类指导文档按版本号分文件夹（v1, v2, v3…）。
- 每次修改时，前一版**完整保留**在旧版本文件夹中，新版本写入新版本文件夹。
- 不在原文件上直接修改。

## 新增文献存放规则

1. 在 `03-原始文献\` 下新建子文件夹，命名：`书名_作者\`。
2. 在 `01-指导文档\文献检索清单\` 下新建对应文献的清单文件夹。
3. 在 `04-检索结果\` 下新建对应的结果文件夹。
